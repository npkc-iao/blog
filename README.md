# Публичные статьи ИАО

Исходники сайта https://npkc-iao.github.io/blog/ (GitHub Pages, Jekyll, тема minima).

- Статьи: `_posts/ГГГГ-ММ-ДД-slug.md`, фронтматер `layout: post`, `title`, `date`, `description`, `tags`.
- Проверка на утечки: `py -3 tools/check_leaks.py` (то же самое запускает CI на каждый push и PR).
- Как публиковать: `КАК_ПУБЛИКОВАТЬ.md`.

Репозиторий публичный: сюда нельзя класть внутренние адреса, имена витрин и таблиц, токены, ФИО пациентов и коллег, номера ОМС/СНИЛС, выгрузки с реальными данными.
