# Как опубликовать статью

1. Черновик пишется во внутреннем vault, публичная версия кладётся в `_posts/`.
2. Перед публикацией вычистить: хосты и серверы, имена БД/схем/витрин, коды процедур и учреждений, id чатов и дашбордов, ФИО (кроме автора), абсолютные объёмы по пациентам (округлять или давать в процентах).
3. Локально: `py -3 tools/check_leaks.py` должен сказать «Утечек не найдено».
4. Статью согласовать с руководством до push в main: после push она сразу появляется на сайте.
5. Коллеги предлагают статьи и правки через fork + Pull Request, мёржит владелец организации.

## Первичная настройка (один раз)

1. На GitHub в организации npkc-iao создать **публичный** репозиторий `blog` (без README).
2. `git remote add origin https://github.com/npkc-iao/blog.git` и `git push -u origin main`.
3. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт откроется по адресу https://npkc-iao.github.io/blog/
